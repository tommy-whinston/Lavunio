# Lavunio

Lavunio — игровой лаунчер команды **TM** для Windows 10/11. Через него можно играть в наши режимы.

## Возможности

- Магазин и библиотека режимов.
- Страница режима с описанием, требованиями и историей обновлений.
- Установка, обновление и запуск сборок.
- Собственные аккаунты Lavunio ID и скины.
- Настройки Minecraft и лаунчера.

## Команда

Проект команды **TM**. Лаунчер и режимы развиваются вместе.

## План развития

Смотри [ROADMAP.md](ROADMAP.md) — там этапы, задачи и правила для разработки.

## Переход с TMStore

При первом запуске Lavunio переносит настройки, аккаунты и состояние библиотеки из `%APPDATA%\TMStore` в `%APPDATA%\Lavunio`. Старый каталог `TMStore-Catalog` остаётся доступен для предыдущих версий, а новый лаунчер использует `Lavunio-Catalog`.
