# Lavunio screenshots

Снимает скриншоты разделов интерфейса в headless-браузере на мок-данных.
Нужен для визуальной проверки вёрстки после изменений стилей.

```powershell
npm run shots
```

## Что делает

1. Поднимает локальный сервер с `src/` и подменяет API мок-данными (как в headless-тестах).
2. Открывает приложение в невидимом Edge/Chrome через CDP.
3. Переключает разделы и окна и сохраняет PNG в `tools/shots/artifacts/`.

## Опции

```text
--width <px>     ширина окна (по умолчанию 1280)
--height <px>    высота окна (по умолчанию 800)
--scenario <s>   сценарий мока: guest, offline, player, admin (по умолчанию admin)
```

## Требования

- Node.js с глобальным `WebSocket`.
- Edge или Chrome (иначе задай `EDGE_PATH` или `CHROME_PATH`).

Скриншоты не коммитятся.
