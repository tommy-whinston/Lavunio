# Lavunio preview

Живой предпросмотр интерфейса в обычном браузере — для быстрой проверки вёрстки и навигации.
Сборка Tauri не нужна: страница открывается сразу, а при изменении файлов в `src/` перезагружается сама.

```powershell
npm run preview
```

Открывается `http://127.0.0.1:7373` в браузере по умолчанию.

## Опции

```text
--scenario <s>   сценарий мока: admin (по умолчанию), player, guest, offline
--port <n>       порт (по умолчанию 7373)
--no-open        не открывать браузер автоматически
```

## Что важно

- Tauri-команды подменены моком: установка, запуск игры, окно и файлы здесь не работают.
- Мок-данные те же, что в headless-тестах (`tools/headless/mock.js`).
- Для проверки реального приложения используй `npm run dev` или собранный `Lavunio.exe`.
