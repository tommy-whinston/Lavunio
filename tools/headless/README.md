# Headless tests

Проверяют лаунчер в невидимом Edge/Chrome без запуска окна Tauri.

```powershell
npm run test:headless
```

## Что проверяется

- статическая проверка ключей i18n:
  - все `tKey(...)` и `data-i18n*` существуют;
  - нет пустых ключей;
  - RU и EN совпадают по набору ключей;
  - нет дублей.
- загрузка приложения без ошибок;
- RU → EN → RU;
- разделы store, library, publisher, team, moderation, messages;
- страница режима;
- настройки и аккаунт;
- реальные сценарии модалок команд, публикатора и модерации;
- confirm;
- данные публикатора и модерации;
- профиль, сообщения, уведомления;
- отсутствие русского текста в EN-интерфейсе;
- отсутствие утечек ключей в текст.

## Требования

- Node.js с глобальным `WebSocket`;
- Edge или Chrome;
- свободные локальные порты;
- приложение не должно быть запущено.

Если браузер лежит не в стандартном месте, задай `EDGE_PATH` или `CHROME_PATH`.
